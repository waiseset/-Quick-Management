功能

分类与二级分类

自定义一级分类与椭圆胶囊式的二级分类，都支持添加、重命名、删除与拖拽排序；删除时会先问清下面的条目怎么处理。

搜索

标题栏的搜索框按名称或描述过滤，跨全部分类查找，清空即恢复。按 Ctrl+F 随时把焦点交给它。

三种条目

应用、网址，以及任意文件（用系统默认程序打开，自动取系统图标）。 添加或拖入 .lnk 会自动定位到真实目标，拖入 .url 自动转成网址条目。

密码隐藏区

可以隐藏任意条目，隐藏后从所有常规视图消失；点左上角菜单的「隐藏的元素」查看，进入需要密码 （图案 / 数字 / 混合，首次进入时自选）。密码只保存哈希，不存明文。 解锁之后的隐藏区与主界面完全一致：单击看描述、多选、右键菜单、快捷键、拖拽排序都能用。

多选与批量添加

Ctrl+左键 逐个加选或取消，Shift+左键 成片选中；复制、剪切、隐藏、删除、收藏一次性作用于整批。 也可以「批量添加应用」一次选多个 exe，自动逐个提取图标。

图标自动提取

添加应用自动取 exe 的系统图标（会裁掉多余透明留白，避免显示得很小），添加网址自动抓取网站图标；也可以随时换成任意本地图片。

单击看描述、双击打开

点一下在标题栏显示描述，双击直接用系统默认方式打开，点空白处取消选中。

收藏 / 复制 / 拖拽

收藏夹只显示已收藏（右上角有金星）；右键可复制、剪切、粘贴，也支持 Ctrl+C/X/V；条目、分类、子分类都能拖着换位置。

数据管理

一键导出 / 导入全部数据（含图标、分类结构、排序、主题），也可以清空所有数据重来。

路径失效提醒

自动检查应用与文件条目的路径是否存在，列出找不到的，可「本次忽略」或「永久忽略」。

深色 / 浅色

两种主题随时切换并记住，导入导出时一并带着走。

两种用法

安装版

快捷管理_3.2.0_x64-setup.exe

  1. 下载后双击，按向导安装（装到当前用户，不需要管理员权限）
  2. 桌面与开始菜单会出现「快捷管理」快捷方式
  3. 数据保存在 %APPDATA%\com.waiseset.quickmanage\
  4. 卸载：设置 → 应用，或运行安装目录里的 uninstall.exe
便携版

快捷管理-便携版.zip

  1. 解压到任意目录（U 盘也行）
  2. 双击其中的 quick-manage.exe 即可运行
  3. 因为压缩包里带了 portable.txt，数据会写在程序旁边的 data\ 目录，不碰系统盘
  4. 换机器直接整个目录拷走，数据一起走
